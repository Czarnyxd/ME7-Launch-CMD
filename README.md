# 🚀 ME7 Launch Control CMD V2

> **A modern Launch Control installer and configurator for Bosch ME7 / ME7.5 ECUs, running entirely from the Windows Command Prompt (CMD).**

This project was created as an improved version of the classic Launch Control installer that has been circulating within the ME7 community for many years.

Unlike the original release, this application is **not limited to installing Launch Control only**. Once Launch Control is detected or installed, the program automatically enters an **interactive configuration mode**, allowing you to modify all major parameters without manually editing the BIN file or reinstalling the patch.

---

# ✨ Features

## 🚀 Interactive Configuration

After detecting or installing Launch Control, the program automatically enters **Configuration Mode**.

You can configure:

* 🚀 Launch RPM
* 🚗 Vehicle Speed
* 🔥 RPM Threshold
* ⚡ Throttle Threshold
* ⏱️ Ignition Cut Duration
* 🔊 Soft Cut / Hard Cut
* 🎮 Activation Trigger

  * Clutch
  * Brake

All configuration is performed directly from the Windows Command Prompt.

No HEX editor or manual BIN modification is required.

---

## 🔍 Automatic Detection

The program automatically detects whether Launch Control is already installed.

If an existing installation is found, it immediately switches to **Configuration Mode** instead of reinstalling Launch Control.

Compatible legacy installations (such as Setzi Launch Control) are also supported.

---

## ✅ Automatic Verification

Every configuration change is verified before the modified BIN file is saved.

The program verifies:

* Launch Control installation
* FTOMN configuration
* Ignition Cut Duration
* Activation Trigger
* Written configuration data
* Output BIN generation

---

## 🛡 Safe File Handling

The original BIN file is **never overwritten**.

Example:

dump.bin

↓


dump_mod.bin


Your original BIN file always remains untouched.

---

# 🔧 Checksum

The current version **does not yet perform automatic checksum correction**.

After configuring Launch Control, the checksum must be corrected manually using **me7sum.exe**.

Example:

cmd

me7sum.exe dump_mod.bin dump_csok.bin


After this step, **dump_csok.bin** is ready to be flashed to the ECU.

Automatic checksum correction will be added in a future release.

---

# ⚠️ Soft Cut (Experimental)

**Soft Cut** is currently considered an experimental feature.

For the best results, the recommended setting is:

* ✅ **Ignition Cut Duration = 20 ms**

Using **200 ms** together with Soft Cut is **not recommended**, as it may produce undesirable Launch Control behavior.

# 📦 Required Tools

For proper operation, several additional tools included with the **Launch V2** package are required.

The following files should be located in the same directory:


Launch V2.exe
ME7Info.exe
ME7Check.exe
me7sum.exe
dump.bin

---

# 📄 Creating the ECU File

The program requires an **.ecu** file containing ECU information used during Launch Control installation and configuration.

This file is automatically generated by **ME7Info.exe**.

Example:


ME7Info.exe dump.bin


After execution, the following file will be created in the same directory:


dump.ecu


At this point, you should have:


dump.bin
dump.ecu


---

# 🚀 Running Launch V2

After generating the `.ecu` file, Launch V2 can be started.

Example:

CMD

Launch V2.exe dump.bin dump.ecu


The program will automatically:

1. Detect Launch Control.
2. Install it if necessary.
3. Enter Configuration Mode.
4. Verify all settings.
5. Save the modified BIN file.

Example:

dump.bin

↓

dump_mod.bin

---

# 🔧 Correcting the Checksum

After Launch V2 finishes, correct the checksum manually.

Example:

CMD

me7sum.exe dump_mod.bin dump_csok.bin


The final file ready for flashing is:


dump_csok.bin
